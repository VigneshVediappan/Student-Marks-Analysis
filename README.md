# Student Marks Analysis

## Aim
To analyze student marks using R programming and calculate total marks, average marks, pass/fail status, and the top-performing student.

## Description
This project uses a simple student dataset containing marks in Mathematics, Science, and English. R is used to perform calculations and identify the best-performing student.

## Technologies Used
- R Programming
- Data Frames
- Basic Statistical Functions

## Features
- Calculates total marks
- Calculates average marks
- Determines pass/fail status
- Finds the top student
- Calculates class average

## How to Run
1. Open `01_Student_Marks_Analysis.R` in RStudio or VS Code.
2. Run the complete program.
3. View the results in the R console.

## Result
The program successfully analyzes student performance and displays the class average and top-performing student.
